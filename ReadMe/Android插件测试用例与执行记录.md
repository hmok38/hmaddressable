### 服务器地址在哪里填

Unity 切换到 Android 后，点击 **HMAA资源管理 → 选择并显示配置表**，在 Inspector 中填写：

| Inspector 标题 | 字段 | 当前已保存的地址 |
|---|---|---|
| 测试资源服务器分发地址 | TestRemoteLoadPath | `https://changan-37-aliyun-cdn-test.benfeigame.com/hmaa/debug/[BuildTarget]` |
| 正式资源服务器分发地址 | RemoteLoadPath | `https://changan-37-aliyun-cdn-test.benfeigame.com/hmaa/release/[BuildTarget]` |

这是 Catalog、hash 和 Bundle 的下载目录。Android 构建时 `[BuildTarget]` 替换为 `Android`，不要重复追加平台目录；同一母包后续热更保持地址不变。

当前 Android 配置资产是 `Assets/HMAddressables/Resources/ConfigHMAddressables.asset`。地址已填写，无需重复操作；以后修改后由我直接读取，不需要你抄写。
