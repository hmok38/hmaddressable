# 功能演示与校验

打开 `Assets/TestScene.unity`。场景已经挂载 `HMAddressableTest`，运行后显示可滚动的演示面板。构建演示程序时，将这个场景作为启动场景加入 Build Settings。

## 资源准备

通过 **HMAA资源管理 → 选择并显示配置表** 配置当前平台。目录名中的 LocalRes、RemoteRes 只是名称，实际本地或远端归属由配置决定；仓库默认配置不保证符合下表，运行完整演示前需核对。

| 演示 | 资源目录 | 配置要求 |
|---|---|---|
| 本地合并 | `Assets/Samples/Test/RES/LocalRes/MultipleTestLocal` | 本地，不加入分散打包列表 |
| 本地分散 | `Assets/Samples/Test/RES/LocalRes/Capsule` | 本地，加入分散打包列表 |
| 远端合并 | `Assets/Samples/Test/RES/RemoteRes/MultipleTestRemote` | 远端，不加入分散打包列表 |
| 远端分散 | `Assets/Samples/Test/RES/RemoteRes/Sphere` | 远端，加入分散打包列表 |
| 本地场景 | `Assets/Samples/Test/SeceneRes` | 本地 |
| 远端场景 | `Assets/Samples/Test/RES/RemoteRes/Scenes` | 远端 |

保留示例原有资源及路径，包括 `LocalRes/New/Cylinder2.prefab`。四项校验以原始示例为基线：Capsule 组只有 `Capsule.prefab` 和 `Cylinder.prefab`，`CapsuleCopy.prefab` 位于 RemoteRes/Sphere。热更后改变成员或路径时，应同步调整校验预期。

填写自己的测试资源服务器地址，关闭强制全部本地和跳过更新。先执行“一键打出包资源(测试包)”，上传 `ServerData/<平台>` 的内容到所填地址对应的平台目录，再构建演示程序。上传时保留子目录；构建程序时沿用这次资源产物。仓库不保存本次测试服务器、母包 state 或构建结果；后续热更应保留自己构建的母包 state 和资源组。

## 面板操作

| 入口 | 查看什么 |
|---|---|
| 四类加载按钮 | 实例出现，面板显示本次路径及加载结果 |
| 列表、组加载和释放 | 多对象加载；释放后可再次加载；“删除所有对象”只删除场景实例 |
| 更新资源 | 显示进度或结果；失败后按钮变为“重试更新” |
| 加载远端场景 | 替换当前场景，原面板随之消失；建议最后执行 |
| 校验资源加载 | 列表、组、重名地址、并发加载及预下载 |
| 校验资源释放 | 按对象、地址、列表、组释放；检查句柄失效、重载及其他资源不受影响 |
| 校验场景生命周期 | 本地与远端场景的并发加载、延迟激活、卸载及重载 |
| 校验并发更新（Android） | 忙碌时拒绝重复调用、回调归属正确、结束后可再次更新 |

四项校验用于真实 Bundle，在构建后的 Android 程序中依次执行。通过时显示“校验通过”，详细结果写入 `[HMAA校验]` 日志。Editor 直接读取资源的成功结果不能代替打包验证。

“校验资源加载”会清除远端合并示例的依赖下载缓存并重新下载，请使用测试环境并保持联网。并发更新需要首个请求仍在执行；全本地、跳过更新或请求已经结束时，不能证明形成了并发。校验设有 15 秒超时，失败后先保存日志，再重启程序复测。

`Assets/Samples/Test/Scripts/link.xml` 保留校验读取的内部字段，使用 IL2CPP 构建演示时需要随脚本保留。这些入口属于示例，不修改插件对外接口，也不覆盖暂缓处理的同进程旧资源缓存问题。
